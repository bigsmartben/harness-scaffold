# Create

1. Confirm the target document and intended audience.
2. Load its Contract and Template from this Skill.
3. Collect every required fact from the current repository.
4. Stop if an executable instruction or decision lacks authority. Use an
   explicit fact gap only for non-blocking optional content.
5. Fill the Template without retaining unused placeholders.
6. Add relative links only when their targets exist or are created in the same
   requested scope.
7. Run the document quality checklist.
8. Report the created path, verified commands or links, and fact gaps.

Example: when creating QUICKSTART, run or otherwise verify the first-success
command and state its observable result.
