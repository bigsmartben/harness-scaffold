# Update

1. Read the existing document before loading the Template.
2. Load the target Contract and identify only the sections affected by changed
   repository facts.
3. Preserve valid prose, stable anchors, relative links, and user-specific
   additions.
4. Replace stale commands, paths, outputs, or decisions only with verified
   current facts.
5. Do not normalize wording or reorder unaffected sections without a stated
   readability reason.
6. Run the document quality checklist.
7. Report changed sections, preserved custom content, validations, and fact
   gaps.

Repeated Update with the same repository facts must produce no change.
