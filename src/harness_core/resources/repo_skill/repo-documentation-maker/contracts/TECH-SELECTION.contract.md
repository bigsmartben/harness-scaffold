# Technology Selection Contract

Map each technology decision to a confirmed capability or constraint. Compare
credible candidates using explicit criteria, record the selected option and
trade-offs, and link reproducible experiment evidence when available.

Mark an undecided item as a fact gap; do not manufacture a final selection.
