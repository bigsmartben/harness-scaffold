# UC Contract

Capture user goals and observable system behavior. Each use case must identify
an actor, trigger, preconditions, main flow, alternate or failure flows,
outcome, and acceptance conditions.

Record UI suggestions only when supported by facts and label them as advisory.
Do not invent business rules or architecture.
